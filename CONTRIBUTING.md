# Contributing

Contributions are welcome. This project is new and has no claimed adoption.

1. Install Python 3.10+ and run `python -m pip install -e .`
2. Run `python -m unittest discover -s tests -v`.
3. Open an issue describing the bug with a minimal JSON example.
4. Add tests when making changes and submit a pull request.

Potential improvements include word-level caption segmentation and multilingual pacing estimates.
